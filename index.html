How it works.

Simple! It uses Permutation

What is a permutation?

A permutation is an arrangement of items where the order matters. If you have three different characters, ABC, each different ordering is a separate permutation.

ABC
3! = 3 × 2 × 1 = 6

When items repeat, the repeated items must be accounted for so that identical arrangements are not counted more than once.

AAB
3! ÷ 2! = 6 ÷ 2 = 3

This calculator handles repeated characters, words, and numbers automatically when duplicate removal is enabled.

Choose your mode

Every arrangement — shows every possible order your input can form.
Random arrangements — creates random samples without trying to enumerate everything.
Valid words — checks generated letter arrangements against WordRift's built-in starter dictionary.

Note: Valid-word mode is intentionally limited to the words bundled into this static page. It does not send your input to a server or use an API. This keeps WordRift fully browser-only.
