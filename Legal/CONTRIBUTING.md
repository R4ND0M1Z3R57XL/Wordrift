# Contributing to WordRift

Thanks for your interest in WordRift!

## Guidelines

Please keep WordRift:

- Simple and fast
- Mobile-friendly
- Accessible
- Privacy-conscious
- Useful rather than feature-bloated
- Free of unnecessary backend complexity

## Workflow

1. Fork the repository.
2. Create a branch.
3. Make and test your changes.
4. Check desktop and mobile layouts.
5. Commit with a clear message.
6. Open a pull request explaining what changed and why.

## Good contributions

- Bug fixes
- Performance improvements
- Accessibility improvements
- Mobile UI improvements
- SEO improvements
- Documentation improvements
- Better permutation handling

## Avoid

- Adding unnecessary backend infrastructure
- Adding unnecessary tracking
- Adding API keys or secrets
- Including unlicensed dictionaries, images, fonts, or libraries
- Removing functionality without a strong reason

## Third-party resources

Clearly document the source and license of any third-party resource added to WordRift.
