# Changelog

All notable WordRift changes are documented here.

## [1.0.0] - 2026

### Added

- Every Arrangement mode
- Random Arrangement mode
- Valid Words mode
- Arrangement counting
- Responsive interface
- Browser-based permutation generation
- Dictionary validation integration
- GitHub Pages-compatible static architecture

### Notes

WordRift is designed to work without a database, user accounts, AI, file storage, or a complicated backend.

Third-party dictionary services remain subject to their own terms, licenses, and attribution requirements.
